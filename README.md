# Track — ระบบวิชาเสริม (ม.4-6)

ส่วนหนึ่งของ **SchoolOS** โรงเรียนสุคนธีรวิทย์ · จัดกลุ่มวิชาเสริม จัดนักเรียนเข้าเรียน
เช็คชื่อ และประเมินผลอัตโนมัติจากการเข้าเรียน · เชื่อมข้อมูลนักเรียน/ครูจาก **Users Service API**

- **Stack:** Next.js (App Router) + TypeScript · Drizzle ORM + PostgreSQL · Tailwind v4 + shadcn-style UI · @react-pdf/renderer
- **พอร์ต:** `3004` (host) → 3000 (container)
- **ฐานข้อมูล:** ใช้ database `tracks` ใน `postgres-core` ที่มีอยู่แล้ว — **สแตกนี้ไม่สร้าง postgres ใหม่**

---

## 1. สถาปัตยกรรม

| ส่วน | รายละเอียด |
|---|---|
| Identity | ไม่มี user/login ของตัวเอง — ยืนยันตัวตนผ่าน `POST /api/public/v1/auth/verify` ของ Users Service |
| Role | มาจาก API: ครูที่เป็น `teacher-admin` → เข้าเป็น **admin**, `teacher` → **teacher**, นักเรียน → **student** — และเพิ่มด้วย “สิทธิ์ผู้ดูแล” ในระบบนี้ได้อีกทาง |
| ข้อมูลนักเรียน/ครู | ซิงก์ทางเดียวจาก Users Service (นักเรียนเฉพาะ ม.4-6) — อ่านอย่างเดียว, **ซิงก์อัตโนมัติ** ตามรอบ |
| ผลการเรียน | คำนวณอัตโนมัติจากการเช็คชื่อ — ไม่ให้กรอกเกรดตรง ๆ (ดู `src/lib/evaluate.ts`) |
| Local admin | มี admin ท้องถิ่นสำรอง 1 บัญชี (bootstrap ตอนบูตครั้งแรก) เผื่อ API ล่ม |

### สิทธิ์ (Roles)
- **Admin** — จัดการทุกอย่าง: กลุ่มวิชา/วิชา, ห้องเรียนพิเศษ, จัดนักเรียนเข้าวิชา, เช็คชื่อ, เวลาเข้าเรียน/ผลรายวิชา, ห้องที่ปรึกษา + รายงาน PDF, ทรานสคริปต์, สิทธิ์ผู้ดูแล, สำรอง/กู้คืน, ประวัติการใช้งาน
- **Teacher** — เช็คชื่อได้ทุกวิชา (ไม่ผูกว่าเป็นผู้สอน), ดูผลรายวิชา, และดูเวลาเข้าเรียน/ผลวิชาเสริมของนักเรียน **เฉพาะห้องที่ปรึกษาของตน**
- **Student** — ดูวิชาเสริมและผลของตนเอง (อ่านอย่างเดียว)

> การจัดนักเรียนเข้าวิชา (register_track) เป็นสิทธิ์ **admin เท่านั้น** — ไม่ใช่ self-service

### สิทธิ์ผู้ดูแล — เพิ่ม admin เฉพาะระบบนี้ (`/admin/permissions`)

ครูบางคนต้องช่วยงานวิชาเสริมโดยไม่ได้เป็น `teacher-admin` ในระบบผู้ใช้ หน้านี้ดึงครูขึ้นมาเป็น
admin **ของระบบวิชาเสริมนี้เท่านั้น**

- เก็บในตาราง `admin_grants` — **ไม่เขียนกลับไปที่ SchoolOS** ไม่ว่ากรณีใด
- สิทธิ์เป็นแบบ **บวกอย่างเดียว**: ครูที่เป็น `teacher-admin` อยู่แล้วยังเป็น admin เสมอ
  ถอนที่นี่ไม่ได้ (แสดงเป็นรายการอ่านอย่างเดียว) — และถอน grant ที่นี่ก็ไม่กระทบสิทธิ์ฝั่ง SchoolOS
- ให้/ถอนแล้ว **มีผลทันทีในหน้าถัดไปที่เปิด** ไม่ต้องรอ session 12 ชม. หมดอายุ
  (`src/lib/authz.ts` อ่าน role ใหม่จาก DB ทุกครั้ง ไม่เชื่อ role ที่ฝังใน JWT)
- ถอนสิทธิ์ของตัวเองไม่ได้ — กันล็อกตัวเองออกจากหน้านี้
- ทุกครั้งที่ให้/ถอน บันทึกลง `activity_logs` (`grant_admin` / `revoke_admin`)

### ซิงก์อัตโนมัติ

ระบบดึง **ปีการศึกษา → นักเรียน → ครู → ครูที่ปรึกษา** ให้เองตามลำดับ (ลำดับนี้จำเป็น:
ครูที่ปรึกษาอ้างครูและผูกกับปีที่ใช้งาน) — ดู `src/lib/auto-sync.ts`

- รอบละ `AUTO_SYNC_INTERVAL_MINUTES` นาที (ค่าเริ่มต้น 360 = 6 ชม., ขั้นต่ำ 5, ใส่ `0` เพื่อปิด)
- หลังบูต ~20 วินาที จะ “ตามให้ทัน” หนึ่งรอบ **เฉพาะเมื่อข้อมูลเก่ากว่ารอบที่ตั้งไว้** —
  รีสตาร์ทบ่อยจึงไม่ทำให้ยิง API ซ้ำ (เช็คจากตาราง `sync_state` ไม่ใช่จากหน่วยความจำ)
- ขั้นที่พังไม่หยุดขั้นถัดไป และ **ไม่ทำให้แอปล้ม** — บันทึกสถานะไว้แทน
- หน้า **ซิงก์รายชื่อ** และ **ปีการศึกษา** แสดงว่าแต่ละอย่างซิงก์ล่าสุดเมื่อไร สำเร็จไหม
  อัตโนมัติหรือกดเอง และรอบถัดไปอีกเมื่อไร · ปุ่มกดเองยังอยู่ครบ (รวม “ซิงก์ทั้งหมดเดี๋ยวนี้”)

## 2. การประเมินผล (หัวใจของระบบ)

`src/lib/evaluate.ts` เป็น **pure function** ทดสอบแยกจาก UI ได้ (`npm test` — 18 เคส
รวมการนับ “เวลาเข้าเรียน” ใน `src/lib/attendance-summary.ts`):

| การเข้าเรียน (ตามวันที่วิชากำหนด) | ผล |
|---|---|
| มาครบทุกคาบที่มีการเช็ค ทุกวัน | **ยอดเยี่ยม** |
| เข้าเรียน ≥ 60% ของวันที่มีคาบ (นับครึ่งวันด้วย) | **ผ่าน** |
| ต่ำกว่านั้น | **ไม่ผ่าน** |
| ยังไม่มีวันที่เช็คชื่อ | **รอประเมิน** |

- แต่ละวันมี 2 คาบ: **เช้า / บ่าย** — คาบที่ครูไม่เคยเช็ค = ไม่นับ (ไม่เสียคะแนน)
- ผลรายวัน: มาครบเช้า+บ่าย = **ยอดเยี่ยม** · มาแค่ช่วงเดียว = **ผ่าน** · ไม่มาเลย = **ไม่ผ่าน**
- วิชาหนึ่งเปิดได้หลาย **รอบเรียน** (`subject_sections`) — คนละกลุ่ม คนละห้อง คนละวัน เก็บแยกกัน
  ผลการเรียนคิดจากรอบที่นักเรียนอยู่ ไม่ปนกับรอบอื่นของวิชาเดียวกัน
- รอบเรียนกำหนด "วันเรียน" เป็น **วันที่จริงในปฏิทิน** (`subject_dates`) เลือกได้ตั้งแต่วันเดียวถึงหลายวัน —
  วันที่เช็คนอกตารางจะถูกกรองทิ้ง และวันที่ยังไม่มีใครเช็คจะไม่นับเป็นวันเรียน

## 3. รันบนเครื่อง dev (ไม่ใช้ docker)

ต้องมี `postgres-core` รันอยู่และ publish 5432 บน host

```bash
cp .env.example .env      # แก้ค่าให้ถูก (โดยเฉพาะ SCHOOLOS_API_KEY)
npm install
npm run db:migrate        # สร้างตารางใน database tracks
npm run dev               # http://localhost:3004
npm test                  # รันชุดทดสอบ evaluate
```

## 4. Deploy ด้วย Docker (production / Portainer)

**สแตกนี้ไม่สร้าง postgres** — ต่อเข้ากับ `postgres-core` ผ่าน network `school-net` (external)

```bash
cp .env.example .env      # ใส่ค่า secret จริงทั้งหมด (ห้าม commit)
docker compose up -d --build
```

ลำดับตอน `up`: `migrate` (ใส่ schema แล้วจบ) → `app` — ไม่มี prompt, ไม่มี seed step
ที่ต้องรันมือ (admin แรกถูกสร้างอัตโนมัติตอนบูตจาก `SEED_ADMIN_*` เมื่อยังไม่มี admin)

- **ทุก secret อยู่ใน `.env` เท่านั้น** — compose ใช้ `env_file`/`${VAR}` ไม่มี hardcode
- ถ้าลืมรหัส admin: `docker compose run --rm migrate npx tsx scripts/seed-admin.ts`
- nginx: ดู `deploy/nginx-track.conf` (path `/track` หรือ subdomain) — พอร์ตแอป **3004**

### ตัวแปรใน `.env`

| ตัวแปร | ความหมาย |
|---|---|
| `APP_PORT` | พอร์ต host (3004) |
| `DATABASE_URL_INTERNAL` | ต่อ `postgres-core` ผ่าน school-net (ใช้ในคอนเทนเนอร์) |
| `DATABASE_URL` | ต่อผ่าน localhost:5432 (ใช้ตอน `npm run dev` / migrate นอก docker) |
| `JWT_SECRET` | ลายเซ็น session ของแอปนี้ (ไม่เกี่ยวกับ SchoolOS) |
| `SCHOOLOS_API_BASE_URL` | เช่น `http://192.168.200.56:3002` หรือ `http://postgres-core-net-host:3002` |
| `SCHOOLOS_API_KEY` | API key `sk_live_...` — scope ที่ต้องมี: `students:read`, `teachers:read`, `auth:students`, `auth:teachers` (และ `years:read` ถ้ามี) |
| `AUTO_SYNC_INTERVAL_MINUTES` | นาทีต่อรอบซิงก์อัตโนมัติ (ไม่ใส่ = 360, ขั้นต่ำ 5, `0` = ปิด) |
| `BACKUP_DIR` | ที่เก็บไฟล์ pg_dump (docker: volume `tracks_backups`) |
| `SEED_ADMIN_*` | admin แรกตอนบูตครั้งแรก |

## 6. ขั้นตอนเริ่มใช้งานครั้งแรก (admin)

1. เข้าสู่ระบบด้วย admin (`SEED_ADMIN_USERNAME` / password ที่ตั้งไว้) หรือครู `teacher-admin`
2. **ปีการศึกษา / ซิงก์รายชื่อ** → ปกติ**ไม่ต้องทำอะไร** ระบบซิงก์ให้เองตั้งแต่บูตครั้งแรก
   เปิดสองหน้านี้เพื่อดูว่าสำเร็จครบไหม (ถ้าอยากได้ทันทีกด “ซิงก์ทั้งหมดเดี๋ยวนี้”)
3. **กลุ่มวิชา** → เพิ่มกลุ่ม (เช่น ET) · **วิชาเสริม** → เพิ่มวิชาในกลุ่ม
4. **จัดนักเรียนเข้าวิชา** → "เพิ่มรอบเรียน" → เลือกหมวด/วิชา → ตั้งชื่อรอบ + ห้องเรียน →
   เลือกวันเรียนจากปฏิทินไทย → เลือกนักเรียน (จากกลุ่มเรียนพิเศษ, สร้างกลุ่มใหม่, หรือติ๊กเลือกเอง)
   → กด **บันทึกรอบเรียน** ครั้งเดียวจบ (เปิดรอบที่ 2 ของวิชาเดิมได้ ไม่ทับกัน)
5. **เช็คชื่อ** → เลือกวัน → เลือกรอบเรียน (บอกห้องที่เรียน) → กด "มาทั้งหมด" แล้วแก้เฉพาะคนที่ไม่มา
   ทั้งเช้าและบ่าย → ระบบคำนวณ **ผลการเรียน** ให้อัตโนมัติ
6. **เวลาเข้าเรียน** → เลือกห้อง → เห็นว่านักเรียนแต่ละคนมากี่ครั้ง ขาดกี่ครั้ง รวมทุกวิชาเสริม
   (ครูประจำชั้นเห็นห้องตัวเองอัตโนมัติ) · **ผลรายวิชา** → ดูเป็นรายรอบเรียน
7. **ห้องที่ปรึกษา** → กด **ออกรายงาน PDF** → เลือกห้อง (ทีละหลายห้องได้) + เดือน → ออกไฟล์
8. **ทรานสคริปต์** → ออก PDF รายห้อง/รายวิชา
9. **สิทธิ์ผู้ดูแล** → เพิ่มครูที่ต้องช่วยงานให้เป็นผู้ดูแลของระบบนี้ (ไม่กระทบ SchoolOS)
